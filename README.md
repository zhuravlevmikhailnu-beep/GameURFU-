# 1. Идея
1.1 Жанр

 - 2D  rpg с видом сбоку 

1.2 Игровой мир

Фантастический средневековый мир


Темы уровней:
 - Лес, подземелье
   
1.3 Сюжет

Игрок — Цель главного героя заключается в защите мира от монстров, а также в исследовании различных мест, связанных с монстрами.

1.4 Персонажи и враги

Игрок:
 - Базовый персонаж(рыцарь)
 - Характеристики: здоровье, урон
   
Враги:
 - Ближнего боя(гоблины, зараженный грибы)
 - Босс ()
 # 2. Геймплей
 
2.1 Логика игры
 - Игрок появляется в деревне, на которую напали монсты
 - Проходит локации, уничтожая врагов
 - Получает награды (оружие)
 - При смерти — игра начинается заново 
   
2.2 Игровые механики
 - Передвижение (WASD)
 - Стрельба / атака (E)
 - Система здоровья и урона
 - Лут (выпадение предметов)
   
2.3 Уровни игры
 - Несколько локаций с монстрами 
В каждой комнате:
 - Враги
 - Награды
 - В конце последнего уровня босс

# 3. Оформление
3.1 Фоны
 - Минималистичный пиксельный стиль(Деревня, лес, данж)

3.2 Персонажи и враги
 - Зараженные грибы
 - Гоблины 
 - Скелет(босс)
   
3.3 Элементы игры
 - Оружие(множественный выбор оружия)
 - UI (здоровье)
   
3.4 Спрайты
Формат: PNG
Размеры (например 32x32 / 64x64)
Спрайт-листы для анимаций
# 4. Техническая часть

(“Техническая красота” лучше переименовать — так звучит гораздо серьезнее)

4.1 Игровой движок

Выбранный движок:
 - MonoGame
Обоснование выбора:
 - В детстве играл в похожую игру и хотел бы попробовать ее воссоздать 
4.2 Архитектура классов

Основные сущности:
 - GameManager
 - Player
 - Enemy
 - Weapon
 - Locations
   
4.3 Архитектурный подход (MVC)
 - Model — данные (статы, состояние)
 - View — отображение (спрайты, UI)
 - Controller — логика управления

4.4 Используемые паттерны
 - Singleton (GameManager)
 - Factory (создание врагов/оружия)
 - Observer (события, UI)
 - State (состояния игрока/врагов)
