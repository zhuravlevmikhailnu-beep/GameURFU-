# 1. Идея
1.1 Жанр
 - 2D платформер с элементами аркады и экшена.
1.2 Игровой мир
 - Фэнтезийный пиксельный мир: тёмное подземелье.
1.3 Сюжет
 - Игрок управляет маленьким слаймом, который пытается убить всех летучих мышей.
1.4 Персонаж (-и) Враги
Главный герой:  
 - Слайм 
Враги/Препятствия: 
 - Летающие мыши
 - Стены
 - Собственное тело 
# 2. Геймплей
2.1 Логика игры
 - Игрок перемещается по квадратному подземелью, убивает мышей, тем самым увеличивает свою длинну и  набирает очки.
2.2 Игровые механики
 - Движение по 4 направлениям
 - Рост при поедании
 - Счёт (score)
 - -Ускорение со временем
 - Спавн мышей в случайных местах
2.3 Уровни игры
 - Бесконечный режим 
 - Усложнение со временем 
# 3. Оформление
3.1 Фоны
 - Основной фон — светлое клеточное поле (grid)
 - Сетка чёткая, тёмные линии на светлом фоне
 - По краям — рамка в стиле подземелья (кирпичный/каменный бордер)
 - Верхняя часть — отдельная панель с интерфейсом (Score)
3.2 Персонажи
 - Слайм выполнен в пиксель-арт стиле
Враги:
 - Пиксельные существа летучая мышь
3.3 Элементы игры (предметы...)
Декоративные элементы:
  - Трещины на полу
 -  Каменные детали
Интерфейс:
 -  Счётчик очков сверху

# 4. Техническая красота
4.1 Игровой движок
 - MonoGame
4.2 Архитектура классов
 - Game1 — основной цикл
 - Slime — игрок (список сегментов)
 - Monster — монстр
 - GameManager — логика игры
 - -CollisionManager — столкновения
4.3 Композиция MVC
 - Model: координаты сегментов, счёт
 - View: отрисовка слайма и еды
 - Controller: ввод (клавиши)
4.4 Архитектура паттерна и классов
 - List/Queue для тела слайма
 - Observer (обновление счёта)
 - State (игра/пауза/конец)
4.5 Реализация паттерна и классов
 - Тело слайма = список позиций
 - Добавление сегмента при еде
 - Проверка столкновений с самим собой
# 5. Тестирование
5.1 Тесты
 - Проверка роста
 - Проверка столкновений
 - Проверка спавна еды
5.2 Тестирование на удобство и понятность
 - Отзывчивость управления
 - Понятность интерфейса
 - Баланс скорости
